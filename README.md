# FUNRUN PUNRUK #4 — PHP + MySQL

ระบบนี้เขียนด้วย PHP แบบไม่ใช้ Laravel, Composer, Node.js หรือ `npm run dev` ใช้ PHP 8.2+, PDO MySQL และ CSS/JavaScript ที่อยู่ในโปรเจกต์ ใช้ฐานข้อมูลใหม่ชื่อ `fun_pun` และไม่อ่านหรือแก้ฐานข้อมูล Laravel เดิม

## ติดตั้งฐานข้อมูลใหม่

ฐาน `fun_pun` บนเครื่องนี้มีตารางและข้อมูลตั้งต้นแล้ว **ไม่ต้อง Import ซ้ำ** หากติดตั้งบนฐานข้อมูลใหม่ที่ยังว่าง ให้เลือกฐานนั้นใน phpMyAdmin เปิดแท็บ **Import** แล้วเลือก `database/schema.sql` ไฟล์นี้สร้างตารางทั้งหมดและใส่ข้อมูลงานวันที่ 30/01/2027, พร้อมเพย์, หน้า Home และ role แอดมิน

ไฟล์ `.env` ในโฟลเดอร์นี้ตั้งให้ใช้ฐาน `fun_pun` แล้ว หากย้ายโปรเจกต์ไปเครื่องอื่น ให้คัดลอก `.env.example` เป็น `.env` แล้วกำหนดค่าเชื่อมต่อ MySQL ของเครื่องนั้น (XAMPP ค่าปกติมักใช้ `DB_HOST=localhost`, `DB_USERNAME=root` และรหัสผ่านตามที่ตั้งไว้)

สร้างผู้ดูแลระบบจาก Command Prompt ที่โฟลเดอร์โปรเจกต์:

   ```cmd
   php database/create_admin.php
   ```

กรอกชื่อ อีเมล และรหัสผ่านอย่างน้อย 12 ตัวอักษร จากนั้นเข้าสู่ระบบที่ `/admin/login`

## เปิดเว็บในเครื่อง

จาก Command Prompt ที่โฟลเดอร์โปรเจกต์:

```cmd
php -m | findstr /I pdo_mysql
php -S 127.0.0.1:8000 -t public
```

เปิด `http://127.0.0.1:8000` และเปิดหน้าต่าง Command Prompt ค้างไว้ระหว่างใช้งาน กด `Ctrl+C` เพื่อหยุดเซิร์ฟเวอร์

## ฟังก์ชัน

- หน้า Home ธีมสวนสนุก มีภาพ Hero, สไลด์, เนื้อหา และ Footer ซึ่งแอดมินแก้ไขได้
- ฟอร์มสมัคร 3 ขั้นตอน กติกาและข้อมูลผู้สมัคร เลือกระยะ เสื้อ และวันรับ Race Kit
- คำนวณราคา สร้าง QR พร้อมเพย์ตามยอดสมัคร แนบสลิป และออก BIB ทันที
- ค้นหาชื่อพร้อมคำแนะนำ และเปิดหรือบันทึกบัตร BIB
- Dashboard พร้อมตัวกรอง ยอดสมัคร ยอดเงิน และสถิติการเปิดแต่ละหน้า
- ตรวจสอบสลิป แก้สถานะการชำระเงิน ปิดหรือเปิดฟอร์มสมัคร
- บันทึกรับเสื้อพร้อมลายเซ็น แก้รูปเสื้อและตารางไซส์ และส่งออกรายงาน CSV ที่เปิดใน Excel ได้

## วางบนโฮสติ้ง

ตั้ง Document Root ไปที่โฟลเดอร์ `public/`; เก็บ `.env`, `config/`, `database/`, `cron/` และ `storage/` ไว้นอก Document Root ตั้ง PHP อย่างน้อย 8.2 และเปิดส่วนขยาย `pdo_mysql` กับ `fileinfo` กำหนด `DB_DATABASE=fun_pun` พร้อมผู้ใช้และรหัสผ่านฐานข้อมูลของโฮสต์ ตั้ง `APP_URL` เป็นโดเมนจริง เปิด HTTPS และให้ PHP เขียนไฟล์ใน `storage/` ได้

ตั้ง `upload_max_filesize=6M` และ `post_max_size=8M` สำหรับไฟล์สลิปและรูปภาพ งาน Cron รายวันใช้ `php /absolute/path/to/project/cron/cleanup.php`

ให้ PHP เขียนทั้ง `storage/` และ `storage/sessions/` ได้ ระบบเก็บ session สำหรับ CSRF และการเข้าสู่ระบบใน `storage/sessions/` แทนโฟลเดอร์ temp ส่วนกลางของ PHP

หน้าแอดมินใช้ตารางบัญชีผู้ใช้และ role ที่สร้างไว้ใน `schema.sql` ส่วนแรกของการสร้างบัญชีแอดมินให้ทำผ่าน CLI เท่านั้น ไม่เปิดหน้าเว็บสาธารณะสำหรับสร้างผู้ดูแลระบบ
